# Content Factory

An end-to-end workflow that turns a webinar or community call into assets you can publish.

MeetStream records the call and returns the transcript, the recording, and who spoke when. Content Factory starts from that finished meeting and produces the pieces a team usually writes by hand afterwards: chapters, clips, captions, quotes, a blog draft, social posts, and visual briefs.

## Status

This repository is being initialized. There is no workflow to run yet. Setup, inputs, and examples will be added here as the pipeline is built.

## Assets

| Asset | What it is |
| --- | --- |
| Chapters | Timed sections of the call, with titles |
| Clips | Short cuts taken from the recording |
| Captions | Caption files aligned to the recording |
| Quotes | Lines worth pulling out, attributed to the speaker |
| Blog draft | A written recap of the call |
| Social posts | Short posts ready to edit and publish |
| Visual briefs | Direction for thumbnails, quote cards, and other artwork |

## Repository scope

- Start from a completed MeetStream meeting: transcript, recording, and speaker timeline.
- Produce the assets in the table above from that one meeting.
- Document how to run the workflow once it is ready.

## About MeetStream

[MeetStream](https://meetstream.ai) is meeting bot infrastructure. A bot joins Google Meet, Zoom, or Microsoft Teams, records the call, and returns a transcript and structured meeting data through an API.
